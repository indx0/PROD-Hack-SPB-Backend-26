# Критерии для Backend-жюри

| Критерий | 0 баллов | 1 балл | 2 балла |
| --- | --- | --- | --- |
| Архитектурные решения | Документ не составлен или отсутствует хотя бы один из 5 обязательных этапов, либо составленный документ не соответствует реально разработанной системе | Документ составлен, разработанная система соответствует документу, но в этапах имеются неточности: — не обоснованные решения — решения, не соответствующие требованиям — требования собраны некорректно | Документ составлен, разработанная система соответствует документу, требования собраны и описаны корректно, все решения обоснованы и полностью соответствуют требованиям |
| Удобство проверки | Нет CI/CD, сборка и деплой вручную | Есть базовые данные, но они неполные или требуют ручного дополнения. Проверка занимает много времени | Полный набор данных, автоматизированные сценарии, чёткие инструкции. Проверка занимает минимум времени |
| Работоспособность | Не удалось проверить, отсутствует Swagger или документация | Базовая автоматизация. Сборка и деплой выполняются из пайплайна | Полная автоматизация. Сборка, деплой, линтинг/тесты запускаются из пайплайна |
| Тестирование | Тестов нет | Есть юнит-тесты, покрывающие основной функционал. (есть отчёт о покрытии из которого понятно, какая функциональность покрыта) | Есть интеграционные тесты, покрывающие основные сценарии. (есть отчёт о покрытии из которого понятно, какие сценарии покрыты) |
| Общее впечатление по блоку | Проект оставляет негативное впечатление | Нейтральное впечатление, проект не выделяется | Проект оставляет положительное впечатление |

# Критерии для Mobile-жюри

| Критерий | 0 баллов | 1 балл | 2 балла |
| --- | --- | --- | --- |
| Гайдлайны и их соблюдение | Значительное несоответсие гайдлайнам | Незначительное несоответствие гайдлайнам | Полное соответствие гайдлайнам |
| Дизайн-система | Отсутствие компонентной базы | Соответсвтие компонентной базе на всех экранах, но с ошибками | Соответствие полной компонентной базе |
| Работоспособность | Нет APK/IPA в репозитории, нету связи с бекендом или связь с бекендом частичная и присутствуют баги | Частичная связь с бекендом или функциональность с ошибками/багами | Все работает с минорными ошибками/багами |
| Понимание кода | Полное непонимание кодовой базы (менее 50% правильных ответов) | Частичное понимание кодовой базы (50–90% правильных ответов) | Осознанное понимание кодовой базы (90–100% правильных ответов) |
| Обработка ошибок | Нет обработки ошибок или валидации полей ввода, наличие крашей приложения, фризы экрана | Нет обработки ошибок или валидации полей ввода, приложение работает стабильно | Все ошибки и невалидные значения корректно обрабатываются, приложение работает стабильно |

# Критерии для Frontend-жюри

| Критерий | 0 баллов | 1 балл | 2 балла |
| --- | --- | --- | --- |
| Работоспособность | На деплое фронтенда нет осмысленного функционала | На деплое фронтенда встречаются мешающие баги или часть функционала не завершена | На деплое фронтенда работает весь заявленный функционал |
| Использование API | Интерфейс не вызывает API, фронтенд не связан с бекендом | Часть данных в интерфейсе не согласована с бекендом | Интерфейс активно использует API и согласован с данными на бекенде |
| Удобство использования (UX) | Интерфейс запутан, его сложно использовать | Интерфейс логичен, но требует улучшений | Интуитивно понятный интерфейс |
| Адаптивность | Адаптивность не проработана, это мешает пользоваться интерфейсом | Адаптивность реализована, но с недочетами | Интерфейсом удобно пользоваться как с ноутбука, так и с телефона |
| Визуальная привлекательность | Дизайн устаревший, элементы не сочетаются | Дизайн функционален, но выглядит не гармонично | Современный, визуально гармоничный интерфейс |

# Критерии для Продакт-жюри

| Критерий | 0 баллов | 1 балл | 2 балла |
| --- | --- | --- | --- |
| Полнота функционала | Основные функции не реализованы | Реализованы ключевые функции, но продукт неполный | Все заявленные функции работают, покрыты основные сценарии |
| Проработанность бизнес-сценариев | Бизнес-сценарии не проработаны | Частично проработанные сценарии, но без деталей | Полноценные бизнес-сценарии с пользовательскими историями |
| Презентация бизнес-ценности | Команда не презентовала бизнес-ценность | Команда презентовала бизнес-ценность, но без аргументов | Команда презентовала бизнес-ценность и потенциал развития с обоснованием |
| Дополнительные функции | Дополнительные функции не реализованы | Есть дополнительные функции, но они не добавляют ценности | Дополнительные функции хорошо реализованы и решают конкретные потребности ЦА |
| Общее впечатление по блоку | Проект оставляет негативное впечатление | Нейтральное впечатление, проект не выделяется | Проект оставляет положительное впечатление |

# Общие критерии

| Критерий | 0 баллов | 1 балл | 2 балла |
| --- | --- | --- | --- |
| Структура презентации | Нелогичная структура, слайды перегружены. | Логична, но без деталей. | Чёткая, с демонстрацией работы продукта. |
| Общее впечатление от проекта | Проект оставляет негативное впечатление. | Нейтральное впечатление, проект не выделяется. | Проект оставляет положительное впечатление. |

Проекты должны соответствовать ряду обязательных критериев. При их невыполнении применяются штрафные санкции, снижающие полученные баллы.

| Критерий | Штраф |
| --- | --- |
| Решение не задеплоено | -20% баллов |
| Несоответствие минимальному набору критериев, описанных в кейсе | -30% баллов |
